# Motion Playground

Небольшая площадка для игр с интерфейсом: убегающая кнопка, пружинящие карточки и шуточные взаимодействия.

Четыре эксперимента: кнопка сдаётся после семи побегов, пружинящие карточки, явно вымышленный прогресс и переворачивающаяся карточка. Клавиатура и касание могут сразу активировать кнопку. Настройка уменьшения движения включает спокойный режим автоматически; ручной выбор сохраняется.

Языки: English, Русский. Тема по умолчанию системная, также есть светлая и тёмная. Без сторонних браузерных библиотек, внешних шрифтов, аналитики и CDN.

## Запуск

```sh
python3 -m http.server 8080 --directory public
```

http://localhost:8080

## Размещение

Размести `public/` в корне домена. Для подпапки GitHub Pages адаптируй абсолютные пути или используй свой домен. `file://` не поддерживается: ES-модулям нужен HTTP. Node.js, база данных и сборка в продакшене не нужны. Настройки хранятся на устройстве.

## Проверки

Node.js 24+:

```sh
npm run build
npm test
npm run check
```
